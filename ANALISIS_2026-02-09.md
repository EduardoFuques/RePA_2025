### 3.4 Resiliencia

```python
# Pool de conexiones con retry
def get_db(max_retries: int = 3, delay: float = 0.5):
    for attempt in range(max_retries + 1):
        try:
            db = SessionLocal()
            db.execute(text("SELECT 1"))
            yield db
        except (OperationalError, InterfaceError):
            time.sleep(current_delay)
            current_delay *= 2  # Backoff exponencial
```

| Característica | Configuración |
|----------------|---------------|
| Pool size | 20 conexiones base |
| Max overflow | 30 conexiones extra |
| Pool timeout | 30 segundos |
| Pool recycle | 1800 segundos |

| Retry logic | 3 intentos, backoff exponencial |
